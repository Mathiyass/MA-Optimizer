## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository
   ```
   git clone https://github.com/Mathiyass/MA-Optimizer.git
   cd MA-Optimizer/ma-optimizer-web
   ```

2. Install dependencies
   ```
   npm install
   ```

3. Start the development server
   ```
   npm run dev:all
   ```

4. Open your browser and navigate to `http://localhost:12000`

### Building for Production

1. Build the application
   ```
   npm run build
   ```

2. Start the production server
   ```
   npm run server
   ```

3. Access the application at `http://localhost:12001`

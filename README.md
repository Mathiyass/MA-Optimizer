## 🚀 Getting Started

### ⚡ Quick Install (Recommended)

<blockquote>
  The easiest way to get started. Open <b>PowerShell as Administrator</b> and paste the following to automatically download and install the latest release.
</blockquote>

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
irm "https://raw.githubusercontent.com/Mathiyass/MA-Optimizer/main/install.ps1" | iex
```

### 📦 Manual Install

If you prefer to install things manually:
1. Navigate to the [Releases](https://github.com/Mathiyass/MA-Optimizer/releases/tag/v11.0) page.
2. Download `v11.0.MA-Optimizer.Installer.Setup.exe` (Installer) or `v11.0.MA-Optimizer.Portable.exe` (Portable).
3. Run the application (Administrator privileges are required for system tweaks to take effect).

## 🏗️ System Architecture

MA Optimizer utilizes a strict separation of concerns, ensuring an ultra-smooth React frontend while heavy system modifications are handled safely by the Electron backend via IPC (Inter-Process Communication).

<details>
<summary><b>⚙️ View Advanced Mermaid Architecture Diagram</b></summary>
<br>

```mermaid
graph TD
    classDef ui fill:#20232a,stroke:#61dafb,stroke-width:2px,color:#fff;
    classDef electron fill:#191970,stroke:#9cf,stroke-width:2px,color:#fff;
    classDef os fill:#0f0e1d,stroke:#00ffff,stroke-width:2px,color:#fff;
    
    subgraph Frontend [React UI / Vite]
        UI[React Router Pages]
        Z[Zustand State]
        F[Framer Motion Animations]
    end
    
    subgraph Main [Electron Main Process]
        IPC[IPC Handlers]
        TS[TypeScript Core Modules]
        L[Winston Logger]
    end
    
    subgraph Windows [Native OS Layer]
        PS[PowerShell Engine]
        Reg[Registry Edits]
        WMI[Hardware Telemetry]
        WinGet[App Installer API]
    end

    UI <-->|Update state| Z
    Z <-->|IPC Bridge| IPC
    F -.->|Render| UI
    
    IPC -->|Exec / Spawn| TS
    TS -->|Logging| L
    TS -->|System Calls| PS
    TS -->|Tweaks| Reg
    TS -->|Telemetry SystemInfo| WMI
    TS -->|Software Packages| WinGet
    
    class UI,Z,F ui;
    class IPC,TS,L electron;
    class PS,Reg,WMI,WinGet os;
```

## 👨‍💻 For Developers

Want to build or customize MA-Optimizer? The project is fully open-source and easy to set up.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [Git](https://git-scm.com/)
- A Windows Operating System *(Required for testing native API calls)*

### Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/Mathiyass/MA-Optimizer.git

# 2. Enter the electron directory
cd MA-Optimizer/ma-optimizer-electron

# 3. Install dependencies
npm install

# 4. Launch Development mode (Vite + Electron concurrently)
npm run dev

# 5. Build standard installer for distribution (outputs to dist-electron/installer/)
npm run dist:installer

# 6. Build portable executable for distribution (outputs to dist-electron/portable/)
npm run dist:portable
```

## 🔒 Safety & Transparency

We believe in **"No Snake Oil"** optimization. Here's our promise to you:

- 🛡️ **100% Open Source:** Every script and registry change is fully inspectable in the `electron/ipc` directory.
- ✅ **Validated Tweaks:** Only officially documented Windows tuning mechanisms are used. No magic placebos.
- ♻️ **Safety First:** Built-in backup engines through standard Windows tools (System Restore Points).

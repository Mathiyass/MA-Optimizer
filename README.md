## 🌌 Overview

**MA Optimizer** is a powerful, beautifully designed system optimization suite tailored for Windows 10 & 11. It bridges the gap between raw system power and user accessibility, wrapping hundreds of deep-level registry tweaks, PowerShell scripts, and system utilities into a fluid, glassmorphic interface.

Whether you're a competitive gamer seeking maximum FPS or a user looking to revitalize a sluggish PC, MA Optimizer provides a safe, transparent, and effective path to peak performance.

## ✨ Key Features

| Category | Description |
| :--- | :--- |
| **📊 Smart Dashboard** | Real-time monitoring of CPU, RAM, Disk, and Network with beautiful telemetry charts. |
| **⚡ Performance** | One-click optimizations for CPU parking, RAM management, and visual effects. |
| **🎮 Gaming Pro** | Reduce input latency, optimize GPU settings, and activate dedicated gaming presets. |
| **🛡️ Privacy Guard** | Control Windows telemetry, disable tracking services, and protect your data. |
| **🧹 Deep Cleaner** | Reclaim disk space by purging temporary files, Windows update caches, and log residuals. |
| **🛠️ System Repair** | Integrated SFC, DISM, and Network repair tools to fix common Windows corruptions. |
| **📥 App Center** | Batch install essential software via high-speed Winget integration. |

## 🚀 Getting Started

### Quick Install (Command Line)
Open PowerShell as **Administrator** and paste the following:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
irm "https://raw.githubusercontent.com/Mathiya-Tech/MA-Optimizer/main/install.ps1" | iex
```

### Manual Install
1. Visit the [Releases](https://github.com/Mathiyass/MA-Optimizer/releases) page.
2. Download `MA.Optimizer.Setup.exe`.
3. Run the installer (Administrator privileges required for system tweaks).

## 👨‍💻 For Developers

Build and customize your own version of MA Optimizer.

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [Git](https://git-scm.com/)
- Windows OS (Required for native API calls)

### Setup
```bash
# Clone the repository
git clone https://github.com/Mathiyass/MA-Optimizer.git
cd MA-Optimizer/ma-optimizer-electron

# Install dependencies
npm install

# Launch Development mode
npm run dev

# Build for distribution
npm run dist:installer
```
